# N2-E2 — Catálogo de Jogos

## Integrantes

Gustavo Henrique Forte

## Descrição

Aplicativo Flutter desenvolvido para a atividade N2-E2.

O aplicativo apresenta um catálogo de jogos com informações de nome, descrição, preço e quantidade disponível.

## Funcionalidades

- Catálogo com três produtos;
- Cards utilizando Stack;
- Indicador de quantidade disponível;
- Navegação para tela de detalhes;
- Navigator.push();
- Navigator.pop();
- Transformação de listas utilizando map() e toList();
- Transformação de números em strings;
- Multiplicação dos valores de uma lista;
- Transformação de palavras em widgets Text;
- Transformação de nomes em botões;
- Registro do ciclo de vida do aplicativo;
- Histórico dos estados recebidos.

## Como executar

Na pasta do projeto, execute:

flutter pub get

Depois:

flutter run
