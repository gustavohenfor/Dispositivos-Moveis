# Atividade Flutter - Agenda de Eventos

Este projeto e a base da atividade sobre widgets, estado, navegacao e ciclo de vida.
Ele foi entregue propositalmente com partes incompletas marcadas como:

`TODO_ATIVIDADE_01` ate `TODO_ATIVIDADE_12`.

## Como preparar

1. Instale Flutter e Android Studio/SDK.
2. Abra um terminal nesta pasta.
3. Gere a estrutura Android, caso ainda nao exista:

```bash
flutter create --platforms=android .
```

4. Baixe as dependencias:

```bash
flutter pub get
```

5. Execute:

```bash
flutter run
```

## Regra da atividade

Nao remova os arquivos fornecidos nem substitua o projeto por outro aplicativo.
Preencha os TODOs indicados no codigo.
